# Problem Statement

## Background

Manufacturing equipment generates operational measurements during production. Unexpected machine failures can cause downtime, product distruption, and increased maintenance cost.

## Problem

Machine failures may occur after operating conditions have already begun showing abnormal patterns. A system that estimates failure risk from machine operating data could help identify potentially problematic equipment earlier.

## Initial Objective

Build a machine learning system that uses operational measurements to estimate the risk of machine failure.

The initial model will use variables such as temperature, rotational speed, torque and tool wear.

## Future Scope

The project may later expand to include:

- anomaly detection
- product quality prediction
- model explainability
- REST API access
- monitoring & logging
- a user-facing dashboard
